# Sigmoidh website

Single-page Minecraft-themed site for [Sigmoidh](https://github.com/adityabavadekar/sigmoidh).
No image assets — every texture is generated procedurally at runtime on `<canvas>`.

> **Meta note:** this website was itself made by Sigmoidh running the `ox-alpha` model via OpenRouter. A terminal coding agent shipped its own landing page. Recursion achieved.

## Develop / build (pnpm only)

```bash
pnpm install
pnpm dev      # local dev server
pnpm build    # outputs to dist/
pnpm preview  # serve the production build
```
